Project Abstract

The Sales Data Analysis System is a Data Analysis Essentials cornerstone project that cleans a raw e-commerce sales export, derives Month/Sales/Hour/City/Region, and analyzes sales trends, product and regional performance, peak shopping hours, and price correlations — presented as an interactive dashboard instead of static console output.

Enhancements Beyond the Raw Dataset

  • Region is derived from the state in Purchase Address (US Census grouping: Northeast, Midwest, South, West) — the raw export only has a full street address.
  • Profit Analysis uses an estimated cost-to-price ratio per product category (e.g. accessories ~60% of price, phones ~82-83%) since the raw dataset has no actual cost column. This is clearly an assumption, not measured cost data.
  • Forecast projects the next 3 months of sales using a simple linear trend (NumPy polyfit) fitted to monthly totals.
  • AI Insights are generated with rule-based logic over the aggregated statistics (top region/product, month-over-month change, peak hour, margin).
